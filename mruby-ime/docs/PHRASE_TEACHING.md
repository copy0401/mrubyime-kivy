# 詞組教學：讓你自己加詞、馬上能打詞

> 引擎已支援「詞組」：把幾個字的形碼連起來，打一整串就出一個詞。
> 內建已帶 20 組常用詞；你也可以在自己的 `.cin`（碼表）或 `engine.rb` 裡加自己的詞。
> 這份教學教你怎麼做，不用改 Kotlin、不用重編 APK。

---

## 1. 內建詞組（預設關閉，註解保留）

引擎提供一組**內建詞組範例**（`BUILTIN_PHRASES`，20 組，全部取自內建形碼碼表、已對照
`assets/mrubyime.cin` 驗證），但**預設全部註解掉、不啟用**——你要哪個就把那一行的
`#` 去掉即可。這是避免預設就打亂原本的單字組字行為。

要啟用：編輯 `engine.rb`（Settings → 輸入法引擎 → 寫入編輯目錄），把想啟用的那行前面的 `# ` 去掉，例如：

```ruby
BUILTIN_PHRASES = {
  "ayyedn" => ["今天"],   # ← 去掉這行的 `# ` 就會啟用「今天」
  # "pnsgz" => ["你好"],
  # ...
}.freeze
```

20 組清單如下（啟用後，打對應的碼就出詞，打到前綴也會補全）：

| 你打 | 出 |
| --- | --- |
| `ayyedn` | 今天 |
| `pnsgz` | 你好 |
| `ciwx` | 中文 |
| `jtinzj` | 打字 |
| `ixpmi` | 我們 |
| `pnspmi` | 你們 |
| `palpmi` | 他們 |
| `ednkm` | 天氣 |
| `dsekbu` | 星期 |
| `daamdo` | 時間 |
| `iqlulxu` | 電腦 |
| `hjg` | 手機 |
| `ypfpben` | 老師 |

啟用後，打 `a y y e d n` → 候選列出現「今天」；打到 `ayy`（前綴）時候選列已出現補全提示。

## 2. 詞組碼怎麼算

詞 = 每個字的形碼**依序相連**：

```
今天 = 今(ayy) + 天(edn) = "ayyedn"
我們 = 我(ix) + 們(pmi) = "ixpmi"
電腦 = 電(iql) + 腦(ulxu) = "iqlulxu"
```

查單字碼：開 `mrubyime.cin`，找 `^<碼> <字>` 那一行。

## 3. 方法一：在自己的 `.cin` 加 `%phrase`（推薦）

你的碼表 `.cin` 原本長這樣：

```
%cname 我的碼表
%selkey 0123456789
%chardef begin
a 日
ay 月
...
%chardef end
```

在 `%chardef end` **之後**加一段 `%phrase begin/end`：

```
%chardef end
%phrase begin
ayyedn 今天 今日        ← 一個碼可以對應多個詞
pnsgz 你好 您好 你們好
abc  我家            ← 你自己編的碼
%phrase end
```

存檔 → Settings「輸入法碼表」匯入 → 下次鍵盤出現即生效。

### 3a. 只有詞、沒有碼（自動推碼）

`%phrase` 的每一行**可以只寫詞、不寫碼**——引擎會自動用每個字的碼接起來當作詞碼：

```
%phrase begin
今天           ← 引擎自動推出 ayyedn（今=ayy + 天=edn）
你好 您好       ← 一行多詞也可以，每個詞各自推自己的碼
                              你好 → pns+gz、您好 → 您(pns?)+好… 各自算
%phrase end
```

限制：**詞裡的每個字都要在 `%chardef` 裡**（才查得到碼）。任何一個字查不到，
該詞就自動略過（同行的其他詞不受影響）。

> 內建 uniliu 碼表的 139,637 行 `%phrase` 就是這個形式，而且**一行一筆**並附上詞頻
> （`你好 121`）——可直接閱讀、直接改。單字不列在 `%phrase`（單字順序一律照
> `%chardef`）；即使你寫了，長度 1 的詞也會被引擎直接忽略。你自己寫的時候一行一筆
> 完全沒問題（量小，不影響速度）。

這些詞同時會進入引擎的**詞集 `@words`**，用來在做「自動組詞」消歧時
優先採用真正的詞（見 3b）。

### 3a-2. 權重：決定候選誰排前面

每一行**最後**如果是一個純數字欄位，它就是那一列（那一組詞）的**權重**：

```
%phrase begin
你好 121             ← 「你好」權重 121
一一九 21            ← 「一一九」權重 21（詞本身是數字也照樣是詞）
今天 今日 500         ← 兩個詞共用權重 500
%phrase end
```

- **只有「兩欄以上、且最後一欄全是 0–9」才算權重**，所以單獨一欄的 `2024`
  仍然是一個詞，不會被誤吃。
- **一字的詞（連同它的權重）一律忽略**：單字順序只由 `%chardef` 決定，`%phrase`
  不會把某個字往前拉、也不會讓它重複出現。要調整單字順序就去改 `%chardef`。
- 權重只影響**排序**：同一個碼的候選、或自動組詞的多個讀法，權重大的排前面
  （例如自動組詞 `gnsgz` 會先出 `你好` 再出 `妳好`；單字 `wr` 則照 `%chardef`
  出 `測 测`）。
- **完全沒寫權重的表，行為與以前一模一樣**（原本的順序不動）。
- 內建表的權重來自語料詞頻（`一 213167`、`我們 39591`、`你好 121`）；
  你要調整哪個詞先出現，改它後面的數字就好。

### 3a-1. 讓「單字碼」後面也跟著顯示你加的詞

有些詞的碼剛好和某個**單字碼**一樣。例如 `測試` = 測(wr)+試(iv) = `wriv`，
但 `wriv` 本身也是「劉」的碼。預設打 `wriv` 只會出「劉」。

只要在 `%phrase` 加一行「測試」，打 `wriv` 就會是：

```
1. 劉     ← 原本的單字碼（在前）
2. 測試   ← 你加的詞（在後）
```

寫法（只有詞、沒有碼即可）：

```
%phrase begin
測試
%phrase end
```

> 為什麼不自動？因為像 `ci`(中) 也能切成 `c`(七)+`i`(後)，`wr`(測) 也能切成
> `w`(五)+`r`(二)……**自動列會出現一堆無意義的讀法**（七後、五二…）。所以要哪個
> 詞就明確在 `%phrase` 寫出來，引擎才列，才不會洗版。

### 3b. 連 `%phrase` 都不用：自動組詞

其實你**不需要** `%phrase`——引擎本來就會把 buffer 切成一段段單字碼，
能切乾淨就把它接成一個詞當候選。所以只要表裡有 `你(pns)`、`好(gz)`，
直接打 `p n s g z` 就會出現「你好」候選。

這也支援更長的組合（打完就出整串），但要注意 **「最大碼清空組字」要關掉**
（預設關，max 140），不然 buffer 到最長單字碼就會停。

**歧義範例**：輸入 `miepsesnm`（想打「微生物」＝微(miep)+生(se)+物(snm)）時，
引擎會列出**所有切法**，並依序排序：**① 詞集裡有的詞優先、② 權重大的、
③ 再用碼數少的**：

| 排序 | 讀法 | 切法 | 詞集 |
| --- | --- | --- | --- |
| 1 | **微生物** | miep + se + snm | ✅ 是詞 |
| 2 | 黴崇勿 | mieps + es + nm | ✕ |
| 3 | 黴一物 | mieps + e + snm | ✕ |
| 4 | 律仨物 | mie + pse + snm | ✕ |

因為 `微`(miep) 的碼剛好也是 `黴`(mieps) 的前綴，貪婪切法會先抓 `mieps`，
但**詞集消歧**會把真正的詞「微生物」拉到第一位——所以直接打 `miepsesnm`
第一個候選就是「微生物」。

**最後一個碼只打一半也會先給答案**：打到 `miepse`（生在打 `snm` 的 `s`）時，
候選列就會出現「微生物」，因為引擎會把前面已完成的碼組起來、再用後面的鍵補完尾碼，
只留下能變成詞集裡已知詞的組合。所以連打時不會出現「打到一半候選突然變成別的字」。

如果某個詞**不在**詞集裡（例如你自己新創的詞），才需要下面的方法：

1. **手選**：在候選列點你要的讀法。
2. **加詞**（推薦）：在 `%phrase` 加一行「微生物」（只有詞、沒有碼），
   引擎自動推成 `miepsesnm`，之後打這串就直接是「微生物」，不必再選。

> 這就是「詞集 + 組合消歧」的用途：純靠單字碼切詞一定有歧義，
> 先看是不是已知的詞、再看詞頻、最後才看碼數，就能大幅減少誤選。

### 3c. 一個字的每一組碼都算

`%phrase` 的查表鍵是「每個字**最短**碼接起來」（三峽區＝`s`＋`egn`＋`fv`＝`segnfv`），
但你不必照最短碼打：自動組詞會把 buffer 切成表裡**任何**合法的碼，再檢查接出來的
字串是不是詞集裡的詞。所以三峽區用 `fooo`、`fxx` 這些替代碼也一樣打得出來：

| 你打的 | 切法 | 候選 0 |
| --- | --- | --- |
| `segnfv` | s + egn + fv（最短碼） | 三峽區 |
| `segnfooo` | s + egn + fooo | 三峽區 |
| `segnfxx` | s + egn + fxx | 三峽區 |
| `segnf` / `segnfo` | 尾碼只打一半 | 三峽區（自動補完） |

組詞會先走一趟「每個碼取第一個字」的標準切法，再走一趟替代字，所以像 `segnfooo`
這種「`seg` 本身也是別的字的碼」的輸入不會被替代讀法擠掉。

## 4. 方法二：直接改 `engine.rb`

編輯引擎（Settings → 輸入法引擎 → 寫入編輯目錄），改 `BUILTIN_PHRASES`：

```ruby
BUILTIN_PHRASES = {
  "ayyedn" => ["今天"],
  "mycode" => ["我的詞"],
}.freeze
```

存檔後回到鍵盤，`BUILTIN_PHRASES` 的每個 key 就是「你打的碼」。

---

## 5. 注意事項

- **「最大碼清空組字」要關掉**（預設就是關，max 140）：詞組碼比單字碼長
  （例如 `iqlulxu` 是 7 碼），開著（max=最長單字碼 5）就打完詞。
- **碼別和單字碼衝到**：`%phrase` 的碼如果剛好也是某個單字碼，單字優先、
  詞組次之（引擎先查 `@table` 再查 `@phrases`）。想讓詞組優先就自己改 `engine.rb`。
- **一個碼可多個詞**：空格分開，例如 `ayyedn 今天 今日`。
- **權重放最後一個欄位**：`你好 121`；同碼候選與自動組詞都會依權重由大到小排。
- **上限**：`.cin` 匯入上限 **4 MB**；`engine.rb`／鍵盤佈局原始碼 **64 KB**。

## 6. 快速驗證

```bash
cd mruby-ime
# 把 engine + 你的測試併起來跑（host mruby）
cat app/src/main/assets/mrubyime_engine.rb your_test.rb > /tmp/run.rb
mruby/build/host-test/bin/mruby /tmp/run.rb
```

測試範例：
```ruby
e = MrubyimeEngine.new
e.load_dictionary("%cname T\n%selkey 0123456789\n%chardef begin\na 日\nay 月\n%chardef end\n%phrase begin\naayedn 今天\n%phrase end\n")
e.input_serialized("a"); e.input_serialized("a"); e.input_serialized("y")
e.input_serialized("e"); e.input_serialized("d"); e.input_serialized("n")
puts e.current_candidates_serialized   # => 今天
```
