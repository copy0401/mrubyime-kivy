放在這個資料夾的 .cin 檔會成為「內建碼表」，出現在設定頁的
「輸入法碼表（.cin）」清單中（檔名去掉 .cin 就是 id）。

例如：
  dicts/cangjie.cin   ->  builtin:cangjie
  dicts/array.cin     ->  builtin:array

支援的 .cin 指令（其他指令會被忽略）：
  %ename   NAME              英文名
  %cname   名稱              顯示名稱（設定頁與 log 會用這個）
  %selkey  0123456789        選字鍵
  %keyname begin ... end     實體鍵 -> 鍵面標籤（同時決定合法字根鍵）
  %chardef begin ... end     編碼 -> 候選字（一行一個候選）
  %phrase begin ... end      詞組：<碼> <詞…> 或只寫詞（自動推碼），一行可多個

注意：
  * 檔案必須是 UTF-8（可含 BOM）；以 # 開頭的行視為註解。
  * 字根鍵可以是任意單一字元（a-z、0-9、標點），不再限定為 31 鍵（嘸蝦米式的舊規則）。
  * 多字詞可以放在 %chardef；目前候選 chip 以單字寬度繪製，詞會比較寬。
  * %phrase 只有詞的寫法會自動用每個字的碼推詞碼；詞裡每個字都要在
    %chardef 查得到，否則該詞略過。量大時建議一行放多個詞（解析較快）。
  * %selkey 可以同時是字根（例如注音 1234567890 既是選字鍵又是聲調鍵）：
    按鍵會先看能不能接成下一個編碼，能接就組字、不能接才選字，不需改 %selkey。
  * 請確認碼表的授權允許隨 App 散布。

使用者也可以在設定頁直接「匯入 .cin…」，不需要重新編譯 App。
